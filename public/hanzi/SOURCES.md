# Hanzi lookup data

`core.json.gz` and `details.json.gz` are generated by `bun run hanzi:build`
(`scripts/build_hanzi_db.py`). Do not edit them by hand.

## Sources

| File | Used for | Publisher / licence |
| --- | --- | --- |
| [`Unihan.zip`](https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip) | `kRSUnicode`, `kTotalStrokes`, `kMandarin`, `kDefinition`, `kIRG_*Source`, variant relations | Unicode Consortium, Unicode Terms of Use |
| [`CJKRadicals.txt`](https://www.unicode.org/Public/UCD/latest/ucd/CJKRadicals.txt) | Kangxi radical number → radical character → unified ideograph | Unicode Consortium, Unicode Terms of Use |
| [`USourceData.txt`](https://www.unicode.org/Public/UCD/latest/ucd/USourceData.txt) | U-source identifiers, review status, IDS, sources and comments for unencoded glyphs (UAX #45) | Unicode Consortium, Unicode Terms of Use |
| [`ids.txt`](https://github.com/cjkvi/cjkvi-ids) | Ideographic Description Sequences | cjkvi-ids, derived from the CHISE IDS database; licence follows the CHISE terms (GPLv2) |

`RSIndex.txt` is no longer published in the UCD (it was withdrawn after
Unicode 16.0), so the radical-stroke index is built directly from Unihan's
`kRSUnicode` and `kTotalStrokes` properties.

## Layout

`core.json.gz` — loaded on first paint:

- `chars`: every encoded CJK unified ideograph in `kRSUnicode`, in code-point order
- `rs`: parallel `radical.residual` values
- `ts`: parallel `kTotalStrokes` values
- `src`: two base-64 digits per character, encoding the `kIRG_*Source` bitmask
- `py`: sparse map from character index to `kMandarin`
- `ul`: sparse map from character index to its `kIRG_USource` identifier
- `radicals`: Kangxi radical table with the stroke count of each radical's ideograph
- `u`: the raw ten-field rows of `USourceData.txt`

`details.json.gz` — loaded once in the background:

- `ids`: index → primary IDS plus alternative decompositions (`\t`-separated)
- `def`: index → `kDefinition`
- `vars`: index → simplified / traditional / semantic / Z / compatibility variants
- `rsAll`: index → every `kRSUnicode` value for characters with regional forms

## Online glyph rendering

The detail panel loads an SVG from [GlyphWiki](https://glyphwiki.org/) for the
selected encoded character (`u<hex>`) or U-source identifier (`utc-…`, `uci-…`).
Nothing is fetched at build time. If the request fails, the panel falls back to
the local font and to the schematic IDS structure preview.

GlyphWiki images are served from GlyphWiki's public SVG endpoint and remain
subject to GlyphWiki's own terms; each detail panel links to the source glyph
page. The structure preview is drawn locally from IDS data and the system CJK
font — it is a schematic arrangement, not a generated font glyph.

## Rebuilding

```sh
bun run hanzi:build
```

The script caches downloads in `.data/hanzi-sources/` (gitignored), writes both
files with a deterministic gzip header, and prints coverage counts. Commit the
regenerated files when the Unicode version changes.
