# i18n (Internationalization)

The start page supports bilingual display in **English** and **Chinese (Simplified)**.

## Architecture

A lightweight custom React Context solution (no external i18n library required):

```
src/lib/i18n/
├── index.tsx      # I18nProvider + useI18n hook
├── en.ts          # English translation dictionary
├── zh.ts          # Chinese translation dictionary
└── LocaleHtml.tsx # Syncs <html lang> with current locale
```

## Supported Locales

| Code | Language            |
|------|---------------------|
| `en` | English             |
| `zh` | Chinese (Simplified)|

## How It Works

1. **Auto-detection** — On first visit, the locale is inferred from `navigator.language`. Chinese language tags (`zh*`) map to `zh`; everything else defaults to `en`.
2. **Persistence** — The chosen locale is saved to `localStorage` under the key `locale`.
3. **Switching** — Click the **中 / EN** button in the navbar to toggle language instantly.
4. **HTML lang** — `LocaleHtml.tsx` updates `document.documentElement.lang` whenever the locale changes (for screen readers and SEO).

## Adding Translations

### 1. Update the translation dictionaries

Open `src/lib/i18n/en.ts` and `src/lib/i18n/zh.ts`. Both files export the same `TranslationKeys` shape, so TypeScript will flag any missing keys.

Example — adding a new key:

```ts
// src/lib/i18n/en.ts
export const en = {
  // ... existing keys
  hello: {
    greeting: "Hello, world!",
  },
};
```

```ts
// src/lib/i18n/zh.ts
export const zh: TranslationKeys = {
  // ... existing keys
  hello: {
    greeting: "你好，世界！",
  },
};
```

### 2. Use it in components

```tsx
import { useI18n } from "@/lib/i18n";

export default function MyComponent() {
  const { t } = useI18n();
  return <h1>{t.hello.greeting}</h1>;
}
```

## Adding a New Language

1. Create a new file (e.g., `src/lib/i18n/ja.ts`) that implements `TranslationKeys`.
2. Import it in `src/lib/i18n/index.tsx` and add it to the `translations` record.
3. Add the locale code to `SUPPORTED_LOCALES`.
4. Update `LocaleToggle.tsx` if you want a three-way (or more) switcher instead of the current binary toggle.
